# Statistical Computing and Data Analysis

A set of self-contained Python notebooks exploring probability simulation, conditional probability and exploratory data analysis.

## Notebooks

| Notebook | Focus | Tools |
|---|---|---|
| [Fair Coin Simulation](Fair%20Coin%20Simulation/) | Simulating fair outcomes from a biased coin and visualizing the resulting probability mass function | NumPy, Matplotlib |
| [BMI Risk Analysis](BMI%20Risk%20Analysis/) | Conditional probabilities over BMI categories using height and weight data | pandas |
| [Titanic Survival Analysis](Titanic%20Survival%20Analysis/) | Conditional probability questions on the Titanic dataset | pandas |

Each notebook directory contains its own README and notebook, along with the dataset where applicable.

## Run

From the repository root:

```bash
pip install -r requirements.txt
jupyter notebook
```

Open the notebook you want to explore and execute its cells.

## Scope

These notebooks are exploratory and educational. Results depend on the datasets and assumptions documented in the individual analyses.
